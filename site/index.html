核心功能

⚡ 多线程高速下载

HTTP/HTTPS 直链 2~32 线程 Range 分片并发，实时进度与速度，支持暂停继续、断点续传。

🔗 双向互通

与安卓版共用同一协议：Windows 开房间安卓加入，或 Windows 加入安卓房间，浏览器访客也能参与。

💬 微信式聊天

文本 + 文件气泡，自己靠右、他人靠左，带发送时间与未读提示。

📁 文件夹互传

支持上传整个文件夹并保留目录结构，下载到本地任意位置。

▶️ 内置播放器

图片、视频、音频均在应用内预览播放，不调用外部播放器。

↩️ 仅撤回自己

只能撤回自己发送的文本和文件，撤回后对所有成员生效。

🎨 现代界面

原生 Qt 卡片式设计，浅色/深色主题切换，非 win32 丑控件。

怎么和安卓连起来？

1

确保 Windows 与安卓在同一 Wi-Fi / 局域网。

2

一端开房间（显示口令与地址 http://IPv4:端口 和二维码）。

3

另一端选「加入房间」，扫码或填地址 + 口令即可一起互传。
